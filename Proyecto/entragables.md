ENTREGABLES
Cada grupo deberá presentar:
1.	Código fuente completo del sistema.
2.	Sistema funcional ejecutable.
3.	Documentación del proyecto, incluyendo:
o	portada,
o	introducción,
o	objetivos,
o	descripción del problema,
o	estructuras implementadas,
o	justificación del uso de cada estructura,
o	operaciones desarrolladas,
o	análisis básico de complejidad,
o	mejoras implementadas.
4.	Manual de usuario.
5.	Manual técnico o de programador.
6.	Manual de implementación.
7.	Sustentación o demostración funcional del sistema.
8.	Evidencias de pruebas realizadas.
